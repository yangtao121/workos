# V3 P0 resident Greenfield Desktop viewer

- Status: in_progress.
- Owner: Desktop Web and client SDK, branch `feat/greenfield-window-viewer` in `/home/aquatao/workos-greenfield-viewer`.
- Scope: retain the live SurfaceAttachment ID; project Runtime native top-level windows into the existing WorkOS shell; render complete PNG tile frames with honest first-frame/reconnect states; send controller-gated pointer, keyboard, IME, focus and resize events; bridge the real Wayland text selection through browser clipboard gestures. Preserve the legacy Xvfb path.
- Dependencies: merged [ADR-0040](../decisions/0040-resident-greenfield-window-media.md) and `GreenfieldWindowService` contract, Runtime/Gateway implementations of the same contract, LAN HTTPS for browser Clipboard API.
- Acceptance: a live observer can view the same native windows but cannot input; each top-level has an existing-shell window with correct parent/z ordering; ready follows one decoded and drawn complete real frame; reconnect and revision changes require full refresh; controller input is sequenced and responds honestly to rejection; browser clipboard success requires a real native selection and browser write; close detaches without stopping Code. Deterministic tests/visual fixtures and live Code/Mac acceptance evidence are separate.
- Implementation: [client architecture](../architecture/greenfield-window-viewer.md). The SDK already exports the generated service from the merged contract; this slice changes Desktop and its window-manager model, not generated SDK code.
- Visual evidence: [before unavailable](../ui/desktop-web/changes/20260926-greenfield-window-viewer/before/greenfield-window--unavailable--1440x900.png), [after unavailable](../ui/desktop-web/changes/20260926-greenfield-window-viewer/after/greenfield-window--unavailable--1440x900.png), [after synthetic resident windows](../ui/desktop-web/changes/20260926-greenfield-window-viewer/after/greenfield-resident-windows--synthetic-ready--1440x900.png), and [fixture/capture notes](../ui/desktop-web/changes/20260926-greenfield-window-viewer/notes.md). Matching after images are current baselines.
- Verification: `corepack pnpm --filter @workos/desktop-web check` (242 tests), `corepack pnpm --filter @workos/window-manager check` (11 tests), `corepack pnpm --filter @workos/desktop-web build`, targeted ESLint/Prettier, and the two fixed-viewport Playwright visual captures. These ran in pinned Node/Playwright Docker images. The remount test proves that one attachment keeps its input sequence across responsive body remounts.
- Outstanding: Runtime/Gateway producer and real Code A04–A10 evidence. The synthetic fixture does not prove native pixels, live observer control, Mac IME, real clipboard, or latency. Status stays `in_progress`; the client implementation alone cannot mark P0 done.

The focused NativeApp 11-test suite, TypeScript typecheck, and fixed 1440×900 Chromium visual test passed in pinned containers. Live A07 still requires the two-browser gate.
