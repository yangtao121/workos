# 启动项目 + 局域网免认证访问(开发调试)

## 背景与结论

- 启动方式:`make bootstrap && make generate && make dev`(全部走 Docker Compose,`network_mode: host`),gateway 在 `127.0.0.1:8080` 服务前端 SPA 和 Connect API,`WORKOS_DEV_AUTH_BYPASS: "true"` 已免认证(固定注入 owner/device 身份)。
- 局域网访问的两个障碍(均在 `internal/platform/config/config.go` 的 `ValidateGateway`):
  1. `config.go:610-613` — DevBypass 强制 loopback 绑定;
  2. `config.go:620-621` — 非 loopback 绑定强制 TLS 证书。
- 已确认 `internal/gateway/gateway.go` 的 `serveDev`(306-342 行)无 Host/Origin 校验,前端用 `window.location.origin` 连 API → gateway 绑定 `0.0.0.0` 后局域网设备直接访问即可,无 CORS 问题。Greenfield 代理在 DevBypass 下也按 http scheme 处理(gateway.go:246)。

方案:新增一个**显式、默认关闭**的开发开关 `WORKOS_DEV_AUTH_BYPASS_ALLOW_LAN`,仅在 DevBypass 开启且该开关显式为 true 时,允许非 loopback 绑定 + 纯 HTTP。生产模式(DevBypass=false)校验完全不变,保持 fail-closed。

## 改动清单

1. **`internal/platform/config/config.go`**
   - `Auth` 结构体(185 行附近)新增字段 `DevBypassAllowLAN bool`(`yaml:"dev_bypass_allow_lan"`),注释写明风险:开启后局域网内任何人以 owner 身份无认证访问,仅限可信开发局域网。
   - `Load()`(546-552 行旁)新增 `WORKOS_DEV_AUTH_BYPASS_ALLOW_LAN` 布尔解析。
   - `ValidateGateway()`(604-636 行):
     - DevBypass 分支:`!isLoopback(host) && !c.Auth.DevBypassAllowLAN` 才报错;
     - TLS 规则改为:`!isLoopback(host) && !(DevBypass && DevBypassAllowLAN) && TLS缺失` 才报错(即该豁免只在 DevBypass 分支生效,生产模式不受影响)。
2. **`internal/platform/config/config_test.go`**
   - 保留 `TestDevBypassRejectsPublicBind`(不开开关仍拒绝,10-18 行);
   - 新增:DevBypass + AllowLAN + `0.0.0.0:8080` + 无 TLS → 校验通过;
   - 新增:仅 AllowLAN(DevBypass=false)+ 非 loopback + 无 TLS → 仍拒绝(生产校验不被削弱)。
3. **`deploy/compose.dev-lan.yaml`**(新文件)— 开发专用 overlay,仅覆盖 gateway 服务两个环境变量:
   ```yaml
   services:
     workos-gateway:
       environment:
         WORKOS_HTTP_ADDRESS: 0.0.0.0:8080
         WORKOS_DEV_AUTH_BYPASS_ALLOW_LAN: "true"
   ```
   (compose 对 environment 做按 key 合并,其余 gateway 环境变量保留;`name: workos` 项目名固定,`make down` 可正常清理。)
4. **`Makefile`** — `dev` 目标(1035 行)旁新增:
   ```make
   dev-lan:
   	docker compose -f compose.yaml -f deploy/compose.dev-lan.yaml up -d --build
   ```
5. **`apps/desktop-web/package.json`** — 新增一行 `"dev:lan": "vite --host 0.0.0.0 --port 5173"`,供局域网前端热更新调试(vite 代理指向 127.0.0.1:8080,与 gateway 同机时可用)。
6. **`docs/tasks/20260926-lan-dev-access.md`** — 按 AGENTS.md 建任务记录(范围、验收、验证命令)。
7. **`README.md`** — 快速开始区(66-89 行,非生成区块)补一行 `make dev-lan` 说明。

## 安全说明(写入代码注释与任务记录)

该开关开启后,局域网内任何设备都以固定 owner 身份获得完整无认证访问,流量为明文 HTTP。仅适用于可信开发局域网;默认关闭,所有现有 fail-closed 行为不变。生产暴露仍走既有的 TLS + 设备配对路径(lan-pairing profile / systemd :443)。

注:本机为 AWS EC2,局域网可达性还取决于 VPC 安全组/防火墙放行 8080 端口——属于仓库外配置,会在交付说明中提示。
